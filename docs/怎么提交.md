## 口 A：麦当劳大赛，去 GitHub 开 Issue

### 提交地址

<https://github.com/M-China/mcd-developer-innovation-challenge/issues/new>

点绿色的 **New issue** 按钮，不用选模板，直接把下面内容填进去。

### 填什么（可直接复制）

**标题**（复制这一行）：

```
【参赛申请】麦门顶饿算账
```

**正文**（整段复制，四行，中间不要加空行）：

```
【参赛申请】
项目名称：麦门顶饿算账
项目地址：https://github.com/xiaofeiliu78-create/mcd-satiety
项目简介：用麦当劳官方 MCP 把门店实时菜单价格和官方营养数据按商品名精确对齐，算出同样的钱怎么点最顶饿、最不容易胖，一条命令给出三档答案和一句能直接转发的话。
```

### 三个会被系统打回的坑

1. **标题和正文之间不要空行**，正文四行之间也不要空行。
2. **项目地址写裸链接**，不要写成 `[项目地址](https://...)` 这种 Markdown 格式。
3. **`项目简介` 那四个字和内容必须在同一行**，不要回车换行。

提交后系统会在 Issue 下自动回复报名成功或失败原因。失败会说明原因，改完重新开一条即可。

## 提交之后：真正决定名次的是 Star

麦当劳那个赛道**只看 GitHub Star 数**，不看代码质量。当前榜单（2026-10-24 20:00 更新）：

- 第 1 名：1224 star
- 第 10 名：516 star
- 第 50 名：约 110 star
- **第 99～100 名：49 star**（这是进榜门槛，而且还在涨，明天大概率到 60 以上）
- Star 为 0 的项目**不进排行榜**

也就是说：交完 Issue 只算报名成功，**要进前 100 还得凑到 50 个以上的 star**。可行的做法：

1. 把仓库链接发到自己的朋友圈、微信群、QQ 群，配一句「帮我点个 Star，参加麦当劳的比赛，点右上角 Star 就行」
2. 在掘金 / 小红书 / 即刻发一篇短文，讲「麦当劳营养表和价目表对不上，我把它们缝起来算了笔账」，文末放仓库链接
3. 找几个技术群互相 star（大赛规则没禁止，但别刷号）

**这件事我做不了，只能你自己发。** 但文章和文案我可以帮你写。
