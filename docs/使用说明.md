# 使用说明

「麦门顶饿算账」——花同样的钱，麦当劳哪一单更顶饿、更不容易胖。

不需要任何技术背景，三种用法任选一种。

---

## 方式一：手机直接打开（最快，什么都不用装）

打开 `web/index.html`（或已发布的在线链接），拖动两个滑杆就行：

1. **预算**：你想花多少钱，默认 ¥35
2. **热量上限**：这一餐最多吃多少大卡，默认 800

页面立刻给出三档答案：**顶饿 / 省钱 / 解馋**。不用注册、不用登录、不用装 App，手机浏览器打开就能用，还可以「添加到主屏幕」当图标。

---

## 方式二：WorkBuddy 技能（能查任意城市、任意门店）

这个方式查的是**实时数据**，不限于内置的那家店。

### 第 1 步：领一个 MCP Token（一次性，约 1 分钟）

1. 手机打开 https://open.mcd.cn/mcp
2. 点右上角「登录」，用手机号 + 验证码登录
3. 登录后点右上角「控制台」→ 点「激活」→ 同意协议，Token 立刻生成
4. 复制这串 Token，存好

### 第 2 步：把 Token 配到 WorkBuddy

在 WorkBuddy 里配置连接器 `mcd-mcp`，填入 Token（或者打开 `~/.workbuddy/mcp.json` 填进 `Authorization` 那一栏，格式是 `Bearer 你的Token`）。

### 第 3 步：装技能

把 `mcd-satiety` 文件夹放到 `~/.workbuddy/skills/` 下面。

### 第 4 步：直接说话就行

在 WorkBuddy 里这样问：

> 我今晚想吃麦当劳，在郑州二七广场，预算 35，别超过 800 大卡，怎么点最顶饿？

> 我在周口万达，只有 20 块，能吃到多少蛋白？

> 减脂期想吃麦当劳，600 大卡以内，帮我配一单

它会问清城市、预算、热量三件事，然后实时调麦当劳官方接口给你算。

## 方式三：命令行（想批量算、或者想跑脚本）

```bash
python mcd_solver.py --city 周口市 --keyword 万达广场 --budget 35 --kcal 800
```

| 参数 | 作用 | 默认 |
|---|---|---|
| `--city` | 城市 | 周口市 |
| `--keyword` | 商圈或门店名 | 万达广场 |
| `--store` | 直接指定门店编码 | 空 |
| `--budget` | 预算（元） | 35 |
| `--kcal` | 热量上限，0 表示不限 | 800 |
| `--json` | 输出结构化数据 | 关 |

需要填 Token：设环境变量 `MCD_MCP_TOKEN`，或让脚本自动读 `~/.workbuddy/mcp.json`。

## 输出长什么样

```
# 麦门顶饿算账｜麦当劳周口文昌万达广场餐厅

预算 ≤ ¥35｜热量 ≤ 800 kcal

## 顶饿
薄皮焦香V翅 × 2
实付 ¥31｜384 kcal｜蛋白 34g
每元 1.10g · 密度 8.9 · 钠 1188mg（占每日 59%，今天别再重口）

## 省钱
双层深海鳕鱼堡 × 1
实付 ¥24｜485 kcal｜蛋白 28g

## 解馋
培根安格斯厚牛堡 × 1
实付 ¥34.5｜707 kcal｜蛋白 34g

## 结论
同样吃 300 大卡，薄皮焦香V翅给你 27 克蛋白，脆薯饼只有 2 克。相差 12.9 倍。

同样吃到约 34 克蛋白，V翅×2 只要 384 大卡，培根安格斯厚牛堡要 707 大卡
——差的 323 大卡，差不多是慢跑 32 分钟。

> 已用麦当劳 calculate-price 接口复核实付 ¥31.00
```

四个数字怎么看：

- **实付**：这一单真实要付多少钱
- **kcal**：这一单多少热量
- **蛋白**：这一单多少克蛋白质
- **每元 / 密度**：每块钱换多少克蛋白 / 每 100 大卡换多少克蛋白

## 常见问题

**为什么推荐炸鸡翅，不是说减脂不能吃炸的？**

因为算的是「同样热量能换多少蛋白」。薄皮焦香V翅 192 大卡换 17 克蛋白，巨无霸 513 大卡换 27 克——按单位热量算，V翅效率高得多。它不是"更健康"，是"更划算"。钠含量我也一并标了，两个 V翅就吃掉每日钠额度的 59%，会提醒你。

**为什么只能算十几个餐品？**

营养数据只覆盖部分餐品，价格数据覆盖另一部分，两边靠菜名对上，能精确对上的就十几个。对不上的我不去猜，因为猜错了价格，算出来的账全是假的。

**能帮我把餐点了吗？**

不能，也不做。这个工具只在你点餐前帮你算账，下单还是你自己在麦当劳小程序里点。涉及花钱的接口它一个都不碰。

**算出来的价格准吗？**

准。推荐组合的金额会用麦当劳官方的算价接口再核一遍，结果里会写「已用 calculate-price 复核实付 ¥XX」。

**数据是实时的吗？**

WorkBuddy 技能版是实时的，能查任意门店。网页版是某个时间点抓下来的快照，页面上写了抓取时间，没有假装是实时的。

---

## 一句话总结

**它不帮你点餐，只帮你决定点什么。** 点餐前 30 秒，给你一个算得清的答案。
