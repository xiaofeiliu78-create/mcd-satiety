## 四项声明

**原创性：** 本作品未抄袭任何现有作品。代码为本次开发过程中由 WorkBuddy 生成，非复制自任何第三方仓库；`mcd_client.py` 与 `mcd_solver.py` 仅依赖 Python 标准库，未引入任何外部依赖。

**AI 协作如实披露：** 开发全过程（含被排除的方案、踩到的坑、反复修改的地方）记录于 [`workbuddy.md`](../workbuddy.md)，未作美化或删减。

**选题基于实测而非推测：** 开发前对麦当劳中国 MCP 的全部 35 个工具做了只读可用性探测，并基于实测结果放弃三个方向（用券凑单、历史订单、积分抽奖）——它们在当时使用的账号上都返回空数据。该过程记录于 `workbuddy.md` 与 [`MCP_INTEGRATION.md`](../MCP_INTEGRATION.md)。

**数据获取方式合规：** 未使用任何反编译、抓包、绕过鉴权等手段，全部数据通过官方 MCP 接口按文档调用取得。

## 数据来源

| 数据 | 来源 |
|---|---|
| 门店信息、营业时间 | MCP `query-nearby-stores` |
| 餐品名称、售价 | MCP `query-meals` |
| 营养成分（能量/蛋白/脂肪/碳水/钠/钙） | MCP `list-nutrition-foods` |
| 订单实付金额复核 | MCP `calculate-price` |

本作品**不存储、不扩散**任何麦当劳的原始数据。每次运行实时调用接口，结果不落库。

## 凭证与安全

- 仓库中**不包含**任何 MCP Token、API Key 或个人账号信息。
- 运行时 Token 由使用者自行配置（环境变量 `MCD_MCP_TOKEN` 或本地连接器配置），不随代码分发。
- 未调用任何具有真实交易副作用的接口：`create-order`、`party-order-create`、`mall-create-order`、`auto-bind-coupons`、`draw-lottery` 均永不主动调用。

## 已知边界

本作品只对「营养库与门店菜单中名称精确一致」的单品进行计算（建表时 19 个，实测会随菜单浮动），对无法对齐的餐品**不做估算**。这是刻意选择：宁可少算，不给假数字。
